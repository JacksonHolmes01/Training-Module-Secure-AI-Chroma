# How to Open a Terminal

You will run all commands in this tutorial inside a terminal.

## macOS
Press Command + Space, type Terminal, press Enter.

## Windows (10 / 11)
This lab uses Bash scripts, so Windows users should work inside **WSL 2** (Windows Subsystem for Linux).

1. Open PowerShell as Administrator and run `wsl --install`
2. Restart your computer when asked
3. Open **Ubuntu** from the Start menu

Run every command in this lab inside the Ubuntu window, not in PowerShell.

## Linux
Press Ctrl + Alt + T or open Terminal from the applications menu.

## Copy / Paste
- macOS: Cmd + C / Cmd + V
- Windows (Ubuntu window) and Linux: Ctrl + Shift + C / Ctrl + Shift + V

## A note on passwords in the terminal
When a command asks for a password, nothing appears on screen as you type. That is normal. Type it and press Enter.
